# Roadmap

## 0.1.x

- Add more command-policy fixtures from real Claude Code sessions.
- Add `costs` report command for the JSONL spend ledger.
- Add copy-paste examples for each hook event.
- Publish first npm package and collect install feedback.

## 0.2.x

- Add project presets for solo maintainers, teams, and high-risk repos.
- Add documented recipes for monorepos and worktrees.
- Add Scorecard and release provenance checks once the GitHub repo is public.
- Add simulator output snapshots for every bundled example.

## 0.3.x

- Add config schema validation with helpful errors.
- Add signed release notes and changelog automation.
- Add a compatibility matrix for Claude Code hook contract changes.
- Add community-contributed policy packs.

## Not planned

- Cloud policy service.
- Telemetry by default.
- Secret scanning that uploads content.
- Automatic command execution on behalf of the user.
