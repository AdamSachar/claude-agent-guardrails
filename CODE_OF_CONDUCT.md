# Code of Conduct

This project uses a simple contributor standard:

- Be direct and respectful.
- Assume bug reports are useful even when the fix is not obvious.
- Do not include secrets, tokens, private prompts, or proprietary code in issues.
- Do not use issues to request bypasses for destructive or abusive automation.

Maintainers may edit, hide, or close contributions that include secrets, harassment, spam, or unsafe bypass instructions.
